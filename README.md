# Tejados — descargas

Juego cooperativo online para 2 enanos: uno en el tejado mide y clava, el otro en el suelo marca,
sierra y lanza las piezas. Hablad mucho: el del suelo no ve los agujeros.

## Descargar
**[Última versión](https://github.com/Dohkku/tejados-builds/releases/latest)**
- Windows: `Tejados.exe`
- Linux: `Tejados.x86_64` (dar permiso de ejecución: `chmod +x Tejados.x86_64`)

No hace falta instalar nada: se descarga y se abre.

## Para jugar juntos
- **Todos con la misma versión** (la última de esta página).
- Uno crea la partida (anfitrión) y el otro se une con su IP. Puerto **UDP 24680**.
- El anfitrión tiene que abrir ese puerto en el router, o usar una VPN de juego
  (Tailscale, ZeroTier o Radmin VPN) y compartir la IP que le dé.
- Windows: la primera vez saldrá el aviso del firewall → **Permitir acceso** (redes privadas y públicas).
- Windows SmartScreen puede avisar de "editor desconocido" → *Más información* → *Ejecutar de todas formas*.
- Que haga de anfitrión quien tenga mejor conexión. El ping se ve en la tarjeta de arriba a la izquierda.

## Controles
WASD · Espacio saltar · Ctrl agacharse · Q gafas de aumento · 1-3 o rueda: herramientas ·
E mantenida agarrar pieza · clic dcho mantenido con una pieza = lanzar · V pulsar para hablar (si se activa) ·
Enter chat · H ayuda · Esc menú
